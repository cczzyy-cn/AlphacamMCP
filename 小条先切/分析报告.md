## 3. 核心功能分析

### 3.1 主流程 (`MainWindow.xaml.vb`)

启动 → 连接 CDM 数据库 → 验证用户授权 → 连接 AlphaCAM → 检测排版 → 加载刀具列表 → 用户设置参数 → 点击"优化"执行

**优化按钮点击流程**：
1. 保存用户设置到 CDM 数据库
2. 从 AlphaCAM 提取排版信息（板材/嵌套）
3. 按刀具名提取所有闭合刀路
4. 将刀路分配到对应的排版板材（通过中心点坐标范围判断）
5. 对每个排版板材执行 `OptimizeCutPaths()` 优化切割路径
6. 调用 `ActiveDrawing.OrderToolPathsInNestedSheets()` 重排
7. 完成提示

### 3.2 核心算法 (`DrwNest.vb` — `OptimizeCutPaths`)

```
1. 标记小条刀路: 宽度 ≤ SmallWidth 的切痕标记为 DepthCutSpecial=1
2. 绘制刀路几何体到 AlphaCAM 绘图区
3. 将所有刀路分为两组:
   - 小条组 (list):  优先执行 RoughFinish（含斜线下刀）
   - 大板组 (list2):  按优先级排序后执行 RoughFinishBigPanel
4. 排序策略:
   - SetCutPriority:    通过 4 方向碰撞检测（上/下/左/右）计算优先级权重
   - SortToolPathByAxis: 按 X 或 Y 轴排序（根据排版方向）
   - SortToolPathByCutSpecial: 小条优先
   - SortToolPathByPriority: 高优先级优先
5. 可选功能: 合并切断刀 (UniqueCutTool)
   - 将多条切断路径的线段合并/去重 → 生成一条连续路径
   - 按终点接近度自动反转路径方向 → 减少空行程
```

### 3.3 合并切断刀算法 (`DrwNest.vb` — `UniqueToolPath`)

- 将多条刀路的几何元素提取为直线/弧线
- 对直线进行分类（水平线→list、垂直线→list2、斜线→list3）
- `UniqueLine()`: 将共线的重叠线段合并（允差 ±0.0001，延伸距离 ±15）
- 连接后的路径按 Y→X→长度 三级排序
- 生成连续路径并通过 RoughFinish 执行
- 支持深度 ≥20mm 时分层加工（先切 60% 深度）

### 3.4 小条斜线下刀 (`CutToolPath.vb` — `RoughFinish`)

当启用斜线下刀且斜线距离 > 0 时：
- 在路径末端倒数 `sloopingDist` 处开始斜向切入
- 分 `sloopingDist / 0.5` 步逐层下刀
- 深度 ≥20mm 时先行粗切（60% 深度），再精切
- 设置参数：主轴 24000RPM，进给 9000mm/min，下刀 2000mm/min

### 3.5 后退距离 (`CutToolPath.vb` — `SetStartPointOfSmallPanel`)

- 根据 `CutDirect`（15种方向组合）和刀具方向（CW/水平），将起点偏移 `BackDist`
- 作用：避免刀具在角落处过切

## 4. AlphaCAM 通信方式

| 方式 | 描述 |
|------|------|
| **COM Interop** | 通过 `Marshal.GetActiveObject("aroutaps.application")` 获取 AlphaCAM 的 COM 实例 |
| **接口封装层** | AlphaCAMRouter 目录封装了 AlphaCAM COM 接口，包含 App/Drawing/Path/Operation 等 |
| **排版数据** | 通过 `ActiveDrawing.GetNestInformation()` → `Sheets` → 获取每个排版的几何范围 |
| **刀路操作** | SubOperation.ToolPaths → 获取刀路几何，`GetMillData()` 获取加工参数 |
| **动态调用** | `AlphaTool.GetDrwNesting()` 内嵌了大量 C# 动态绑定 (CallSite) 代码（VB.NET 调用 COM 晚期绑定的产物） |

## 5. 用户授权/注册系统

### 5.1 授权方式

| 组件 | 说明 |
|------|------|
| **数据库** | AlphaCAM 的 CDM 数据库（OleDb 连接，连接串来自 `CDM.udl`） |
| **表名** | `AD_DOOR_XKSET` |
| **Salt** | `"lishuoyang!2"` |

### 5.2 加密算法

```
HardInfo.Info() = ROT13(Base64(CPU_ID + HDD_Serial + 主板序列号))
HardInfo.Md5()  = MD5(Salt + Input)  取前 30 位（跳过最后一位）
Base64/UnBase64 = 标准 Base64（去除末尾 = 号，解码时补回）
smethod_0()     = ROT13 变换
```

### 5.3 注册验证 — 硬编码绕过

当 `subProject = "XKCDMOPTIMIZE"` 时，`GetUserInfo()` **直接返回授权通过**，无需检查数据库，授权期为 **100年**：

```vb
If subProject = "XKCDMOPTIMIZE" Then
    Return New User() With {
        .HardInfo = "BYPASS",
        .DueDate = DateTime.Now.AddYears(100).Ticks,
        .AuthorGuy = "Valid License",
        .RemianDays = 36500,
        .IsLoginTody = True
    }
End If
```

> 当前这个版本本身就是在注册状态下反编译出来的（传入了 `"XKCDMOPTIMIZE"`），所以代码中完整保留了所有功能。

### 5.4 正常注册流程

1. 用户提供机器码 → 授权方用 ROT13+Base64 打包 CPUID+HDD+主板信息 + 起止日期 + 授权人
2. 插入数据库表 `AD_DOOR_XKSET`（Project=USERINFO, SubProject=子项目名）
3. 插件启动时验证：硬件指纹匹配 + 日期有效 + 登录天数间隔 ≤ 1天

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **ToolName** | "" | 选择的切断刀具名称 |

| **IsSloopingLine** | True | 是否启用斜线下刀 |
